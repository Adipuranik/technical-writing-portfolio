# IoT Sensor Data Format Documentation

## Overview

This document describes the XML structure used to represent sensor data generated by an ESP32-based temperature and humidity monitoring system.

## Data Fields

| Field       | Type     | Description                    |
| ----------- | -------- | ------------------------------ |
| device_id   | String   | Unique device identifier       |
| temperature | Decimal  | Temperature in °C              |
| humidity    | Decimal  | Relative humidity percentage   |
| status      | String   | Device operating status        |
| timestamp   | DateTime | Time the reading was generated |

## XML Example

```xml
<?xml version="1.0" encoding="UTF-8"?>

<sensorReading>
    <deviceId>ESP32-001</deviceId>
    <temperature unit="Celsius">28.6</temperature>
    <humidity unit="percent">62.0</humidity>
    <status>active</status>
    <timestamp>2026-08-20T10:30:00</timestamp>
</sensorReading>
```

## Structure

* `<sensorReading>` is the root element.
* `<deviceId>`, `<temperature>`, `<humidity>`, `<status>`, and `<timestamp>` store sensor information.
* `unit` is an XML attribute used to describe the measurement unit.

Example:

```xml
<temperature unit="Celsius">28.6</temperature>
```

## Validation Notes

* XML must contain one root element.
* Every opening tag must have a closing tag.
* Element names should use consistent formatting.
* Sensor values should contain valid data.

## Intended Audience

Developers, technical support teams, and users working with IoT sensor data.
